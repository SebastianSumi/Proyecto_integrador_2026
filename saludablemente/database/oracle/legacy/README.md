# Archived Oracle SQL — non-executable

This directory preserves pre-consolidation Oracle material moved on 2026-09-14:

- `root-oracle/` contains S01/S02/S03 academic fragments.
- `spring-resources-db/` contains former `src/main/resources/db` scripts.

They are retained only as historical/academic evidence. They contain obsolete schemas, table names, privilege models, and in some cases placeholder credentials. They must **not** be mounted by Docker, configured as Spring SQL initialization, adopted as Flyway migrations, or run against any database.

The active local source is `../local/`; controlled changes are in `../manual-migrations/`.
