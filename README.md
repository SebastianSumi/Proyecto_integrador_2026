# 🌿 Saludablemente

Sistema web full-stack para la gestión del programa de salud ocupacional **Universidad Saludable** de la Universidad Peruana Unión.

El proyecto digitaliza el proceso de evaluación nutricional, aptitud física y promoción de la salud, centralizando la información del personal, las actividades y el seguimiento clínico en una sola plataforma.

---

## 📖 Descripción

**Saludablemente** es una plataforma desarrollada como Proyecto Integrador para los cursos de **Análisis y Diseño de Sistemas (ADS)**, **Base de Datos II (BD2)** y **Lenguaje de Programación II (LP2)**.

El sistema permite administrar:

* Evaluaciones nutricionales
* Evaluaciones de aptitud física
* Actividades saludables
* Registro de asistencia
* Alertas clínicas
* Recomendaciones mediante IA
* Reportes personalizados
* Gestión de usuarios y roles

Su objetivo es reemplazar el uso de fichas físicas y hojas de cálculo, facilitando el seguimiento histórico del estado de salud del personal de la institución.
